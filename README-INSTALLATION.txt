JOKEMA INN PUBLIC WEBSITE — VERSION 1.0

DEPLOYMENT TO jokemainn.com.pg
1. Open your hosting control panel (such as cPanel).
2. Confirm jokemainn.com.pg is connected to the correct document root.
3. Enable an SSL certificate for the domain.
4. Open File Manager and enter the domain document root (commonly public_html).
5. Upload this ZIP and extract its contents directly into that folder.
6. Make sure index.html is directly in the document root, not in a nested folder.
7. Visit https://jokemainn.com.pg and test the website on desktop and mobile.

WEBSITE STRUCTURE
- index.html: homepage
- pages/: accommodation, dining, bar, events, services, about, gallery, contact and privacy
- assets/css/style.css: responsive styling
- assets/js/main.js: mobile navigation and enquiry form demo

FUTURE ADMINISTRATION APPLICATION
This package is the public website only. It does not include administrator login or a CMS.
The separate administration dashboard will later connect to this website and allow exactly three
authorised administrators to manage approved content and sections.

BEFORE GOING LIVE
- Confirm and add official address, telephone, email, map, opening hours and social accounts.
- Add approved photographs and verified room, menu, event and service information.
- The enquiry form is a front-end demonstration only; it does not send or store submissions.
  Connect it to the Jokema Inn JIMS application or a secure approved backend before launch.
- Configure backups, HTTPS, privacy procedures and hosting security.
- Verify all business information with Jokema Inn management. No unverified prices or contact
  details have been invented in this package.
